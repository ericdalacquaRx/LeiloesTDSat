# LeiloesTDSat

## Sobre o projeto
O LeiloesTDSat é um sistema desenvolvido para uma casa de leilões, com o objetivo de gerenciar o cadastro e a listagem de produtos disponíveis para leilão. O sistema permite o registro de novos itens e a consulta dos produtos já cadastrados, servindo como base para as operações de controle de estoque da casa de leilões.

## Tecnologias utilizadas
- Java
- MySQL
- NetBeans (IDE utilizada no desenvolvimento)
